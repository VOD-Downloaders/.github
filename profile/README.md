# VOD Downloaders

Welcome to my central hub for VOD downloading related projects. I support downloading off of Dispatcharr & more...  
All of these projects are largely written in Rust :crab:.

## Projects

The user-facing functionality is spread across these projects:

- [VOD-Downloader-cli](https://github.com/VOD-Downloaders/VOD-Downloader-cli) - Command-line interface for downloading VODs off of [FMHY](https://fmhy.net/video) sites.
- [VOD-Downloader-docker](https://github.com/VOD-Downloaders/VOD-Downloader-docker) - Docker container with WebUI for downloading VODs off of [FMHY](https://fmhy.net/video) sites.
- [Dispatcharr-cli](https://github.com/VOD-Downloaders/Dispatcharr-cli) - Command-line interface for downloading VODs off [Dispatcharr](https://github.com/Dispatcharr/Dispatcharr)
- [Dispatcharr-plugin](https://github.com/VOD-Downloaders/Dispatcharr-plugin) - Plugin to extend [Dispatcharr](https://github.com/Dispatcharr/Dispatcharr)'s VOD downloading capabilities

## Core

The core functionality is created in these "core" projects which are then used in the plugins or cli tools.

- [VOD-Downloader-core](https://github.com/VOD-Downloaders/VOD-Downloader-core) - Core functions for downloading off of [FMHY](https://fmhy.net/video) sites.
- [Dispatcharr-core](https://github.com/VOD-Downloaders/Dispatcharr-core) - Core functions for downloading off of [Dispatcharr](https://github.com/Dispatcharr/Dispatcharr) sites.
